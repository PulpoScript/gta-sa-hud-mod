//  VERIFICAR POSICIONES — script de SOLO LECTURA (no modifica nada)
// #####################################################################
//
//  Para qué sirve: comprobar las direcciones candidatas de posición del
//  HUD para el Modo 3 (docs/INVESTIGACION.md, sección 5). Las listas de
//  los foros no dejan claro si cada dirección es la instrucción o su
//  operando, así que se leen las dos interpretaciones.
//
//  Uso:
//    1. Compilar con Sanny Builder 4 -> verificar_posiciones.cs
//    2. Quitar UI.cs y los .cs de prueba de CLEO\ y poner este.
//    3. Cargar partida y capturar cada mensaje (uno cada 6 s, 13 en
//       total; el último dice "Fin").
//    4. Borrar verificar_posiciones.cs de CLEO\ y volver a poner UI.cs.
//
//  Cada mensaje: "Nombre: a b c | d e f"
//    a = 2 bytes en dirección - 2 (instrucción, si la dirección es el operando)
//    b = 4 bytes en la dirección (puntero)
//    c = float al que apunta b, en bits (0 si b no es del ejecutable)
//    d = 2 bytes en la dirección (instrucción, si la dirección es la instrucción)
//    e = 4 bytes en dirección + 2 (puntero)
//    f = float al que apunta e, en bits (0 si e no es del ejecutable)
//  Un puntero se considera del ejecutable si está entre 0x800000 y
//  0xCFFFFF; si no, no se lee.
// #####################################################################

// ---------------------------------------------------------------------
//  Leer: lee las dos interpretaciones de la dirección en 10@.
//  Devuelve 12@ 13@ 14@ (10@ es el operando) y 15@ 16@ 17@ (10@ es la
//  instrucción). Usa 11@ como temporal.
// ---------------------------------------------------------------------
:Leer
// ---- Interpretación 1: 10@ es el operando ----
0085: 11@ = 10@
11@ -= 2
12@ = read_memory 11@ {size} 2 {vp} False
13@ = read_memory 10@ {size} 4 {vp} False
14@ = 0
if 13@ > 0x7FFFFF
then
    if 13@ > 0xCFFFFF
    then
        14@ = 0
    else
        14@ = read_memory 13@ {size} 4 {vp} False
    end
end

// ---- Interpretación 2: 10@ es la instrucción ----
15@ = read_memory 10@ {size} 2 {vp} False
0085: 11@ = 10@
11@ += 2
16@ = read_memory 11@ {size} 4 {vp} False
17@ = 0
if 16@ > 0x7FFFFF
then
    if 16@ > 0xCFFFFF
    then
        17@ = 0
    else
        17@ = read_memory 16@ {size} 4 {vp} False
    end
end
return
